Quy tắc tạo dark theme bằng code

  • Mọi Form: set BackColor = (13, 17, 23), ForeColor = (201, 209, 217)
  • Button thường: tạo class FlatButton kế thừa Button, override OnPaint. FlatStyle = Flat + custom border (gradient).
  • DataGridView: phải set thêm EnableHeadersVisualStyles = false, gán ColumnHeadersDefaultCellStyle.BackColor, DefaultCellStyle.BackColor, GridColor.
  • TextBox dark khó hơn: phải tạo UserControl bọc TextBox + Border thủ công (vì TextBox không có Border property).
  • ListBox / DataGridView: RowHeadersVisible = false, CellBorderStyle = SingleHorizontal.
  • Mọi panel: BackColor đồng nhất, tạo cảm giác "layer" — vùng đậm hơn ở ngoài, vùng nhạt hơn ở giữa.

Custom paint kỹ thuật quan trọng

Để có button đẹp như mockup (gradient + hover effect), không thể chỉ set BackColor. Phải kế thừa Button và override:

protected: virtual void OnPaint(PaintEventArgs^ e) override {
    auto g = e->Graphics;
    g->SmoothingMode = SmoothingMode::AntiAlias;

    // Vẽ background gradient
    auto rect = ClientRectangle;
    auto brush = gcnew LinearGradientBrush(rect,
        Color::FromArgb(33, 38, 45),
        Color::FromArgb(22, 27, 34),
        LinearGradientMode::Vertical);
    g->FillRectangle(brush, rect);

    // Vẽ border
    auto pen = gcnew Pen(Color::FromArgb(48, 54, 61));
    g->DrawRectangle(pen, 0, 0, Width - 1, Height - 1);

    // Vẽ text
    TextRenderer::DrawText(g, Text, Font, rect,
        Color::FromArgb(201, 209, 217),
        TextFormatFlags::HorizontalCenter | TextFormatFlags::VerticalCenter);

    delete brush; delete pen;
}

Lý do KHÔNG dùng NuGet package cho dự án này

  1. C++/CLI + NuGet = nhiều bug: Microsoft hiện chỉ hỗ trợ tốt NuGet cho C# / VB.NET. C++/CLI có .vcxproj khác với .csproj, NuGet không tự động cấu hình references đúng.
  2. Designer không hỗ trợ custom controls C++/CLI: dù cài MaterialSkin / Guna OK, khi drag-drop vào ProcessListForm sẽ thường báo lỗi "Could not load type". Phải khởi tạo bằng code.
  3. Demo cho thầy: nếu thầy chạy trên máy không có DLL → app fail. Self-contained luôn an toàn hơn.
  4. Học thuật: tự code custom paint → cộng điểm. Dùng thư viện = không học gì về GDI+.
