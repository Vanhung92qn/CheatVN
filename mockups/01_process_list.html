Lưu ý khi thiết kế

  • Anchor properties rất quan trọng — đảm bảo form resize đúng. DataGridView phải anchor 4 phía, các button anchor Bottom|Right.
  • Dark theme: WinForms cũ KHÔNG tự dark được. Phải set BackColor/ForeColor cho từng control. DataGridView cần set thêm EnableHeadersVisualStyles=false, DefaultCellStyle.BackColor, ColumnHeadersDefaultCellStyle.BackColor. Mình sẽ giúp viết code này sau.
  • Icon trong cột Tên: cột Name dùng DataGridViewImageColumn hoặc custom paint. Phase 1 tạm thời chỉ hiển thị text, sang Phase 4 ta thêm icon.
  • Emoji 🔍 🎯 ↻: hoạt động trong Segoe UI font, nhưng nếu xấu có thể đổi sang text "Search", "Open", "Refresh".
